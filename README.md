# SQL Technical Support Portfolio

## Overview

This repository demonstrates how SQL can be used in a Technical Support environment to troubleshoot customer issues, validate application data, and analyze database records using MySQL Workbench.

The project includes a small relational database, sample data, and real-world troubleshooting scenarios using basic SQL queries.

---

## Technologies Used

- MySQL Workbench
- MySQL
- SQL

## SQL Troubleshooting Scenarios

### 1. Find Missing Orders
Identify customers who have not placed any orders.

### 2. Find Duplicate Customers
Detect duplicate customer email addresses.

### 3. Find Failed Transactions
Retrieve failed payment transactions for troubleshooting.

### 4. Find Device Logs
Display device log records for issue investigation.

### 5. Find User Login History
Review user login activities and login status.

### 6. Find Inactive Users
Identify users who have not logged in for more than 90 days.

### 7. Check Database Integrity
Detect orphan records and validate database relationships.
